# 일본 운전 시뮬레이터 (Japan Driving Sim)

일본 렌터카(알파드) 운전 전에 좌측통행·신호·止まれ·주차 규칙을 몸에 익히기 위한 3D 웹 시뮬레이터입니다.

참고: 울트라위스키 「일본에서 운전하는 법 완벽 정리🚗」 https://youtu.be/lUlTnUY2rXk + 팀 메모

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 정적 빌드
```

## 조작

| 키 | 동작 |
|---|---|
| W | 엑셀 |
| S | 브레이크 (후진 아님) |
| A / D | 핸들 |
| 기어봉 클릭 또는 1~4 | P / R / N / D (정차 상태에서만 변속) |
| Q / E | 좌 / 우 깜빡이 |
| X | 와이퍼 (깜빡이 반대쪽 레버 체험) |
| C | 1인칭(운전석 오른쪽) / 3인칭 |
| H | 법규 요약 패널 |
| T | 체크리스트 접기 |
| ⌫ | 출발 지점으로 리셋 |

## 모바일 (터치)

- 가로 모드 전용. 세로로 들면 회전 안내가 뜹니다. 테일스케일 주소로 폰에서 접속하면 됩니다.
- 레이아웃은 Dr. Driving / Car Parking류 모바일 운전 게임 방식: 왼쪽 아래 드래그 핸들(놓으면 중앙 복귀), 오른쪽 아래 BRAKE·GAS 페달(멀티터치), 그 위에 P/R/N/D, 핸들 위에 ◀ ▶ 깜빡이, 가운데 아래에 시점·와이퍼·체크·법규 버튼.
- 📱 기울이기 버튼으로 자이로 조향 전환 (iOS는 권한 팝업, 켜는 순간의 자세가 중앙).
- 홈 화면에 추가하면 전체 화면 PWA(`public/manifest.webmanifest`, 아이콘 포함).
- 성능: 픽셀비 1.5 제한, 그림자 1024, 안개 거리 단축. 데스크톱에서 `?touch=1`을 붙이면 터치 UI를 강제로 볼 수 있습니다.

## 지도

- 3×3 교차로. 가운데(0,0)는 화살표 신호, 네 모서리는 止まれ, 동쪽(90,0)은 유턴 금지.
- 출발 도로(z=0)를 동쪽으로 가면 오른쪽에 편의점. 앞서가는 차가 편의점 앞에서 갑자기 멈춰 우회전 대기함.
- 중앙 교차로에서 남쪽으로 가면 왼쪽에 지정 주차장(P).

## 미션 모드 (게이미피케이션)

- 시작 화면에서 난이도 선택 → 미니맵의 🏁 목적지 3곳을 순서대로 최대한 빨리 (편의점 → 지정 주차장 → 공항 터미널). 목적지 6m 안에서 정차하면 도착.
- 난이도별 위반 허용: 초급 5회 · 중급 3회 · 상급 0회(1회면 실패). 위반 = 정지선·신호·역주행·보행자·충돌 등 점수가 깎이는 모든 항목.
- 초과 시 미션 실패 → 위반 내역 표시 → Enter로 다시 도전.
- 완주 시 난이도별 TOP 5 랭킹. 진입하면 이니셜 3글자(←→↑↓ 또는 클릭, 알파벳 키 직접 입력) 등록. 기록은 브라우저 localStorage(`jds.rank.<난이도>`)에 저장.

## 공유 랭킹 서버 (선택)

기본은 브라우저 localStorage에만 저장됩니다. 팀원끼리 랭킹을 공유하려면 Cloudflare Workers + KV(무료)로 API를 올리면 됩니다. 코드는 `server/`에 있습니다.

```bash
npx wrangler login          # 브라우저로 1회 로그인
./server/deploy.sh          # KV 생성 + Worker 배포 → https://jds-rank.<계정>.workers.dev 출력
```

출력된 주소를 `.env.production`의 `VITE_RANK_API=`에 적고 `git push`하면 GitHub Pages 빌드에 반영돼 모두가 같은 랭킹을 봅니다.
테스트용으로는 브라우저 콘솔에서 `localStorage.setItem('jds.rankApi', 'https://...')` 후 새로고침해도 됩니다.
서버가 꺼져 있거나 미설정이면 자동으로 로컬 저장으로 돌아갑니다.

- API: `GET /rank?diff=easy|normal|hard|all`, `POST /rank {diff, name(3글자), time(초), violations}`. 난이도별 상위 20개 보관.
- 🏆 랭킹 버튼(키보드 R)으로 언제든 조회. 내 이니셜은 초록색으로 표시.

## 학습 체크리스트 (12개)

좌측통행 · 깜빡이 · 좌회전 작게 · 우회전 크게 · 빨간불 전부 정지 · 화살표 신호 · 止まれ 완전 정지 · 보행자 우선 · 앞차 거리 유지 · 우측 가게 진입 · 지정 주차장 · 초록불 유턴

위반 시 안전 점수가 깎이고 이유가 표시됩니다.

## 구조

- `src/config.js` 도로망·치수·구역 정의
- `src/world.js` 도로·차선·횡단보도·신호등·표지판·건물 생성
- `src/vehicle.js` 플레이어 차량 모델 + 기구학적 자전거 물리
- `src/traffic.js` 신호 제어, AI 차량, 편의점 시나리오 차량, 보행자
- `src/rules.js` 교통법규 판정 엔진 + 체크리스트
- `src/ui.js` HUD·기어봉·미니맵·토스트
- `src/mission.js` 미션 코스·난이도·타이머·실패/성공·랭킹
- `src/touch.js` 모바일 터치 조작(핸들·페달·기울이기)
- `src/rankapi.js` 랭킹 저장소(서버/로컬 자동 전환)
- `server/` 공유 랭킹 Cloudflare Worker + 배포 스크립트
- `src/main.js` 렌더러·카메라·루프 (`window.__sim` 디버그 훅)
